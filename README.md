A Python program that writes one original deadpan one-star review of an everyday essential for [One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629) on make.fun.

The review:

> One star. Sleep takes eight hours every night and returns me to the exact same problems, only now I am also late for them.

## Run it

```sh
python3 main.py
```

It writes the review (122 characters) to `/output/entry.txt`.
